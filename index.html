Prism

A MacOS External for Roblox.

Features

ESP

See players through walls with health bars, distance labels, tracers and name tags.

Aimbot

Advanced targeting with customizable FOV radius and smoothness settings.

Local Player

Adjust walkspeed, jump power, gravity, and enable noclip for exploration.

Server Tools

Server hop instantly, rejoin current game, find populated servers, or join by job ID.

FFlags

Access Roblox feature flags with automatic ClientAppSettings.json generation.

Game Info

View place ID, job ID, player count, server region, and game version in real time.

Profiles

Save and load configuration profiles, export and import settings.

Console

Integrated command console for automation, debugging, and advanced control.

Color Picker

Customize colors for ESP boxes, aimbot circles, and team-based targeting.

Anti-AFK

Automatic protection against idle disconnections to keep you in game longer.

Monitoring

Live status indicators, activity logs, uptime tracking, and connection state.

Visual Tweaks

Fullbright rendering, custom fonts, flat skies, and texture quality overrides.
